# UNSTUCK

> Understand what's really going on before you make a move.

UNSTUCK is a privacy-first relationship intelligence product for talking stages, dating, situationships, relationships, breakups, and people from the past.

## Core principles

- Value before account creation.
- Users do not need chat history to get value.
- Users can Tell, Answer, or optionally Show a conversation.
- AI provides evidence-based signals, not mind-reading.
- Collect less, retain less, expose less.
- Security is a constraint from the first commit.
- Ranca is the AI orchestration layer.
