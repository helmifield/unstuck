# UNSTUCK UI V2 — Art Direction

Status: LOCKED — implementation source for UI V2.

## Core direction

UNSTUCK is editorial, minimal, premium, Gen-Z, calm, slightly playful, spacious, and emotionally intelligent. It must not resemble a generic AI assistant, dating app, SaaS dashboard, or gamified mental-health app.

## Modes

Dark mode is REQUIRED for V1. Light and dark are one design language, not separate products.

### Light
- Warm ivory base
- Near-black typography
- Restrained semantic accent
- No neon or rainbow gradients

### Dark
- Deep near-black base
- Warm off-white typography
- Same restrained semantic accent
- No purple AI-gradient aesthetic

## Onboarding

Onboarding is REQUIRED to be interactive and alive.

Flow:
Launch → What's Going On? → Situation → Tell → Analysis → The Read

Motion may include:
- ambient line-art movement
- typography reveal
- gesture/tap response
- state transitions
- subtle progress movement
- responsive visual changes

Motion must be purposeful, fast, premium, and reduced-motion aware. No bounce-heavy, gimmicky, or forced cinematic animation.

## Visual language

Use typography and whitespace as the primary structure. Use restrained hand-drawn/editorial line art as a supporting visual element, not decoration on every screen.

The launch should communicate:

"Something feels unclear.\nLet's make sense of it."

The result hierarchy remains:

THE READ → SIGNALS → WHY → WHAT THIS DOESN'T MEAN → NEXT MOVE → optional CURIOSITY HOOK

## Interaction

Use a small component vocabulary. Interactions should feel tactile and intentional. Do not introduce card-heavy dashboards, badges, chips, gradients, or excessive UI chrome.

## Preview / QA

The browser preview is a visual QA representation of the native iOS implementation. It is not a web product and must not become a second product architecture.

The existing native iOS implementation and centralized design tokens remain the technical source of truth. Exact values should be centralized and changeable, never scattered through screens.

## Reference

Use the approved UI V2 visual mockup supplied by the product owner as art direction. Match its composition, hierarchy, restraint, dark/light behavior, and interactive character rather than copying incidental browser/QA chrome.
